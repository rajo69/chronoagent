\section{System Design}
\label{sec:system}

\sys{} sits between a LangGraph~\citep{langgraph}-orchestrated agent
pool, built on LangChain~\citep{langchain} primitives, and a shared
Chroma~\citep{chromadb} vector memory. It exposes three control-plane
components:

\paragraph{Behavioral Monitor (\cref{sec:methodology:signals}).}
For every PR-handling step, each agent emits six scalar signals:
response latency, retrieval count, output token count, KL
divergence against a pre-attack baseline distribution, tool-call
frequency, and memory-query entropy. The monitor persists these
signals to SQLite (dev) or PostgreSQL (prod) for offline analysis
and streams them to the Temporal Health Scorer.

\paragraph{Temporal Health Scorer (\cref{sec:methodology:detector}).}
The scorer combines two detectors on the dominant signal
(KL divergence): a Bayesian Online Change-Point
Detector~\citep{adams2007bocpd} that flags regime shifts from its
run-length posterior, and a Chronos~\citep{chronos}
probabilistic forecaster that supplies an expected-range prior. A
weighted sum of the two anomaly scores (default weights 0.5 and 0.5)
sets the agent's health score in $[0, 1]$; a sustained normal regime
lets the score recover.

\paragraph{Decentralized Task Allocator (\cref{sec:methodology:alloc}).}
New PRs are offered via a lightweight contract-net-style negotiation
protocol~\citep{contractnet}; each agent submits a bid equal to its
static capability for the task type multiplied by its current health
score. The allocator assigns the task to the highest bid above a
configurable threshold, or escalates to a human reviewer when no
agent clears the threshold. A drifting agent's health score drops,
its bid falls, and work routes away from it automatically, without
a centralized kill-switch.

\paragraph{Human Escalation Layer.}
When an agent's health score drops below a configurable threshold
(default 0.3), or a document is moved to quarantine, the system raises
an escalation that a reviewer resolves through the API and the
dashboard, rather than silently quarantining agents.
