\section{Discussion}
\label{sec:discussion}

\paragraph{Temporal context matters.}
Reactive baselines only see the current query or the current action,
so a slow-drifting attack (MINJA's gradient-descent flavor) can walk
just under their threshold. Temporal monitoring reframes detection as
``is this agent now different from itself six steps ago?'' -- a
question that is easier for the defender to answer than ``is this
query malicious?''.

\paragraph{Pre-specified Pivot A (\texorpdfstring{$\awt{} = 0$}{AWT = 0}).}
The proposal set strictly positive Advance Warning Time as the
hypothesis and pre-specified Pivot A for the alternative. The
measurement showed \emph{concurrent} detection at the moment the attack
takes effect, so Pivot A applied; that is what the Phase 10 runs
measure. The decision is documented in \texttt{docs/phase1\_decision.md}.

\paragraph{Scope of the evaluation.}
\begin{itemize}
  \item The signal set is fixed at six scalars.
  \item Chronos (T5-small) runs as a zero-shot forecaster.
  \item The evaluation covers two published attack recipes; \sys{}
  complements input-level guards.
  \item Throughput numbers come from the MockBackend simulator.
\end{itemize}

\paragraph{Threat model boundary.}
\sys{} defends against an attacker who can write to shared memory but
does not have direct control over an agent's weights or its system
prompt. Weight-level compromises and prompt-level compromises are out
of scope and would be flagged by orthogonal defenses.
